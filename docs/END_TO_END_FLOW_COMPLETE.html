⑤ The Unlock — Razorpay self-serve flow live

1 · CLIENT

Tap “Unlock full plan · ₹X”

unlockPlanCheckout()

Button shown only when access.paymentAvailable is true.

2 · SERVER

Create order

POST /payments/order

Price & keys from Platform Settings; writes a Payment (status created).

3 · BROWSER

Razorpay checkout

checkout.razorpay.com

Opens with the order + key_id; card / UPI / netbanking.

4 · SERVER

Verify signature

POST /payments/verify

Timing-safe HMAC of order|payment; marks Payment paid.

5 · UNLOCK

Open the plan

unlockCandidatePlans()

Flips previewOnly→false; Journey refreshes, all days open.

⛑ FALLBACK

Webhook

POST /payments/webhook

Public, signature-verified payment.captured — unlocks even if the browser drops. Idempotent.

Mentor-assisted path: “Talk to a mentor” raises a mentor Concern → the team closes via CRM, then unlocks from the /assessment-candidates dashboard. Both paths converge on the same unlockCandidatePlans().
