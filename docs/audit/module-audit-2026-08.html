How to read this

A percentage means: the feature's data model, API, admin surface and student surface all exist, and the path has been exercised. A module can be 100% built and 0% used — those are different problems, and the notes say which.

Why only 21 of 90. Assigning a completion figure to a module I have not opened would be a guess wearing the costume of a measurement. The 69 unassessed modules are listed by name at the end; auditing them properly is a further pass, not a paragraph.

Gaps, by consequence

Each is something observed, not inferred. The evidence is stated so any of it can be re-checked.

Redis is reachable from the internet with no password

critical

Confirmed by connecting from outside the server: 187.124.97.56:6379 → +PONG, firewall inactive. Unauthenticated Redis is a standard remote-code-execution path via CONFIG SET dir. The box was compromised by a cryptominer in July. 91 live BullMQ keys mean it cannot simply be stopped — it needs binding to localhost.

Daily labs cannot launch: 145-day plans are 28% and 21% full

blocks launch

All delivery infrastructure is finished and deployed. A track cannot be published with empty days — by design — so no batch can run a full plan. 110 thinking and 115 communication concepts remain to author. This is now the critical path, not code.

Three paid Passport surfaces have never been run

revenue risk

Practice, Mock Interview and Resume are entitlements behind a ₹499 payment. SQL practice was verified end-to-end against production Piston this session; the other two have shipped across roughly 25 deploys without a single execution by anyone, including us.

Authorisation coverage is incomplete

high

29 route files carry no roleGuard, and 4 controllers hold hardcoded role arrays that bypass the permission system entirely — assessmentSchedule · communication · liveClass · payment. Permission groups themselves are well modelled; enforcement is not uniformly applied.

One server runs three products

high

14 containers share 8 vCPU: LMS, CRM and VoicePilot together with MongoDB, Redis and Piston. A Tech Battle at scale degrades all three. There is also no staging environment — a temporary one had to be built to load-test, then torn down.

Realtime cannot scale horizontally

medium

socket.io is used in 29 places with no Redis adapter, so a message emitted by one worker never reaches clients on another. Node clustering is therefore opt-in and off by default: safe for the HTTP-only battle path, unsafe for live classes and notifications.

Gamification measures one lab

medium

XP comes solely from Thinking Lab. Communication Lab tracks streaks separately and feeds no XP, so a leaderboard used to award prizes currently ignores half the daily work students are being asked to do.

An orphaned record and a stale data path

low

One graded submission references a deleted user. Separately, 34 of one student's 40 attempted quizzes point at content no longer visible to them — historical, not broken, but it means raw attempt counts overstate current work.
