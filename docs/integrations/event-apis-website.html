Event Registration API

Build one dynamic registration page on codebegun.com that works for every workshop, hackathon or webinar. The CodeBegun team creates each event in the LMS (name, fields, closing date); your page reads the fields from this API, draws the form, and posts the registration back.

How it fits together

  1. The CodeBegun team creates an event in the LMS (Leads → Event APIs) and gives it an API name, for example java-workshop-nov-2026.
  2. Your events page calls List open events to show what is open right now.
  3. Your registration page, for example codebegun.com/events/java-workshop-nov-2026, calls Get one event's form and draws the inputs from fields.
  4. On submit, your page sends the answers to Submit a registration. Show the returned message, or show each error under its field.

Nothing about a particular event is hard-coded on the website. When the team adds a field, changes a label or closes an event, your page follows within about a minute.

Keys are stable, labels are not. Send answers using each field's key. Show the label to people. Labels can change at any time; a key never changes once the event has registrations.

List open events

GET/api/v1/public/events/codebegun

Every event that is live and not past its closing date, soonest closing first. Use it for an "Upcoming events" listing.

{
  "success": true,
  "data": [
    {
      "name": "Java Full Stack Workshop – Nov 2026",
      "apiName": "java-workshop-nov-2026",
      "description": "Two-day hands-on workshop…",
      "opensAt": null,
      "closesAt": "2026-11-30T18:29:00.000Z",
      "status": "open"
    }
  ]
}

Dates are ISO 8601 in UTC. Show them in India time (Asia/Kolkata). An event that has not opened yet can appear here with status: "not_yet_open".

Submit a registration

POST/api/v1/public/events/codebegun/{apiName}

Header Content-Type: application/json. The body is a flat object: one property per field key, plus these optional extras:

PropertyPurpose
_hpSpam trap. Add a hidden text input named _hp to every form (hidden with CSS, not type="hidden", with tabindex="-1" and autocomplete="off") and send whatever it contains. People leave it empty. If it has a value, the API answers as though the registration succeeded but stores nothing.
utm_source, utm_medium, utm_campaign, utm_term, utm_contentCopy these from the page's own URL when present (for example ads linking to ?utm_source=instagram). The team sees the source next to each registration.
 
POST /api/v1/public/events/codebegun/java-workshop-nov-2026
Content-Type: application/json

{
  "name": "Ravi Kumar",
  "phone": "9876543210",
  "college": "JNTU Hyderabad",
  "year": "3rd",
  "utm_source": "instagram",
  "_hp": ""
}

Properties that are not fields of this event are ignored. Do not add extra validation rules of your own beyond required and the input types; the API is the source of truth and returns a message for every problem.

Responses and error codes

Every response is JSON with success. Failures also carry code (stable, for your logic) and message (readable, safe to show).

HTTPcodeWhenWhat to do
201—RegisteredShow data.message and hide the form
400VALIDATION_FAILEDOne or more answers are missing or invalidShow each message from errors under its field (keys match field keys)
403EVENT_CLOSEDPast the closing dateShow message; hide the form
403EVENT_NOT_OPENBefore the opening dateShow message
403EVENT_PAUSEDPaused by the teamShow message
404NOT_FOUNDUnknown eventShow a not-found page
409DUPLICATEThis mobile is already registered (only on events set to one per mobile)Show message
429—Too many attempts from one networkShow message; the Retry-After header gives the seconds to wait
500SERVER_ERRORSomething failed on our sideShow message and let the person try again

Complete example

A dependency-free page script. It reads the API name from the URL (/events/<apiName>), draws the form, and handles every response above. Adapt the markup to the site's design.

<div id="event"></div>
<script>
const API = 'https://platform.codebegun.com/api/v1/public/events/codebegun';
const apiName = location.pathname.split('/').filter(Boolean).pop();
const root = document.getElementById('event');
const esc = (s) => String(s ?? '').replace(/[&<>"]/g, (c) => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[c]));

function input(f) {
  const req = f.required ? 'required' : '';
  const ph = f.placeholder ? `placeholder="${esc(f.placeholder)}"` : '';
  switch (f.type) {
    case 'textarea': return `<textarea name="${f.key}" ${req} ${ph}></textarea>`;
    case 'select': return `<select name="${f.key}" ${req}><option value="">Choose…</option>${
      f.options.map((o) => `<option>${esc(o)}</option>`).join('')}</select>`;
    case 'multiselect': return f.options.map((o) =>
      `<label><input type="checkbox" name="${f.key}" value="${esc(o)}"> ${esc(o)}</label>`).join('');
    case 'checkbox': return `<input type="checkbox" name="${f.key}" ${req}>`;
    default: {
      const t = { email: 'email', phone: 'tel', number: 'number', date: 'date', url: 'url' }[f.type] || 'text';
      return `<input type="${t}" name="${f.key}" ${req} ${ph}>`;
    }
  }
}

async function load() {
  const res = await fetch(`${API}/${apiName}`);
  if (res.status === 404) { root.innerHTML = '<p>This event does not exist.</p>'; return; }
  const { data } = await res.json();
  const ev = data.event;
  const closedText = {
    closed: 'Registrations are closed.',
    paused: 'Registrations are paused for now.',
    not_yet_open: `Registrations open on ${new Date(ev.opensAt).toLocaleString('en-IN', { timeZone: 'Asia/Kolkata' })}.`,
  }[ev.status];
  root.innerHTML = `<h1>${esc(ev.name)}</h1><p>${esc(ev.description)}</p>` + (closedText
    ? `<p>${closedText}</p>`
    : `<form novalidate>
        ${data.fields.map((f) => `<div class="field" data-key="${f.key}">
          <label>${esc(f.label)}${f.required ? ' *' : ''}</label>${input(f)}
          ${f.helpText ? `<small>${esc(f.helpText)}</small>` : ''}
          <div class="error"></div></div>`).join('')}
        <input name="_hp" tabindex="-1" autocomplete="off" style="position:absolute;left:-9999px" aria-hidden="true">
        <button type="submit">Register</button><p class="form-message"></p>
      </form>`);
  const form = root.querySelector('form');
  if (form) form.addEventListener('submit', (e) => submit(e, data.fields));
}

async function submit(e, fields) {
  e.preventDefault();
  const form = e.target;
  const body = { _hp: form._hp.value };
  for (const f of fields) {
    if (f.type === 'multiselect') body[f.key] = [...form.querySelectorAll(`[name="${f.key}"]:checked`)].map((x) => x.value);
    else if (f.type === 'checkbox') body[f.key] = form.querySelector(`[name="${f.key}"]`).checked;
    else body[f.key] = form.querySelector(`[name="${f.key}"]`).value;
  }
  const qs = new URLSearchParams(location.search);
  for (const k of ['utm_source', 'utm_medium', 'utm_campaign', 'utm_term', 'utm_content']) if (qs.get(k)) body[k] = qs.get(k);

  form.querySelectorAll('.error').forEach((el) => { el.textContent = ''; });
  const button = form.querySelector('button'); button.disabled = true;
  try {
    const res = await fetch(`${API}/${apiName}`, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(body) });
    const out = await res.json();
    if (res.status === 201) { form.innerHTML = `<p>${esc(out.data.message)}</p>`; return; }
    if (out.errors) for (const [key, msg] of Object.entries(out.errors)) {
      const box = form.querySelector(`.field[data-key="${key}"] .error`); if (box) box.textContent = msg;
    }
    form.querySelector('.form-message').textContent = out.message || 'Something went wrong. Please try again.';
  } catch {
    form.querySelector('.form-message').textContent = 'Could not reach the server. Check your connection and try again.';
  }
  button.disabled = false;
}
load();
</script>

Always escape labels, options and messages before inserting them as HTML, as esc() does above. They are written by staff, but treat them as text.

Limits, caching and testing

  • Cross-site requests: allowed from codebegun.com; no API key or login is needed.
  • Caching: the two GET calls are cacheable for 60 seconds (Cache-Control: max-age=60). Don't cache POST.
  • Rate limit: 300 registrations per 15 minutes from one network. That is enough for a whole college lab registering at once; beyond it you get 429.
  • Duplicates: an event can be set to one registration per mobile; a repeat gets 409 DUPLICATE.
  • Not supported yet: file uploads, and non-Indian phone numbers in phone fields. Use a text field if international numbers are needed.
  • Testing: ask the CodeBegun team to create a test event (for example website-test), point your page at it, and submit freely. The team can delete test registrations from the Data screen, then pause or close the test event.
  • The registration list is only visible to CodeBegun staff in the LMS. This API never returns other people's registrations.

Go-live checklist: the page shows each status correctly, shows per-field errors, includes the hidden _hp input, passes UTM values through, and shows data.message after success.
