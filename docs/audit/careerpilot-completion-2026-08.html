What actually blocks the sale — ranked

01Prepare Interviews is emptyContent

All 20 companies sit below the readiness bar, so the student-facing list is blank and every company URL 404s by design. Cognizant needs 10 more questions and is otherwise live-ready; IBM needs 20. The other 18 need 20 questions and an eligibility tick each.

Fix — no code. Admin → Companies → Import / Generate. One company crosses the bar in roughly ten minutes.

02The live price is ₹499, not ₹1,599Fixed 12 Aug

Production passportconfigs.priceInr read 499, so every paywall and Razorpay order quoted that number. Now corrected to 1,599 and confirmed on the live public config endpoint. Membership term is 12 months.

Still to prove — blocker 03 below. A correct price is not the same as a working payment.

03No payment has ever completedUnproven

39 members exist; zero have a paid membership. Order creation and signature verification are implemented and share the LMS's Razorpay rail, but the path from "student taps Buy" to "entitlements unlock" has never executed against real money in production.

Fix — one live ₹1 transaction end to end, then refund. Until that passes, treat revenue as untested.

04Mock interviews are uncappedMissing code

You specified 12 per member per year. The code checks membership and nothing else, so cost per member is unbounded. At ₹2.42 per interview, one enthusiastic member running one a day costs ₹883/year against a ₹1,599 membership — before any other AI spend.

Fix — a counter on the session start endpoint. Half a day, and it is the single highest-leverage guard before 10,000 members arrive.

05Coins cannot be spentHalf built

Earning, capping, ledgering and admin dials are all real. There is no spend path at all — so the economy currently teaches members that coins are meaningless, which is worse than not shipping it.

Fix — one redemption catalogue plus a spend function with the same idempotency discipline as earning. Referrals and certificates can follow.

06Two features missing from the entitlements configFixed 12 Aug

Defaults only apply when a document is created, and production's predated Tech News and Company Questions. Both are now registered as paid — the config holds all 11 features, so their tier is editable in Admin → Config and the client receives a lock state for them instead of undefined.

Effect — paid members now see Tech News and the company hub as unlocked in the UI, not merely reachable by the server.
