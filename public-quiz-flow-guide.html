Edge Cases & Scenarios

What to do in every situation

A

Normal flow (Week Config saved BEFORE approving)

This is the ideal path. You set up the week first, then approve students.

  1. Save Week Config (quiz + schedule)
  2. Approve student → token auto-assigned
  3. Send quiz links when ready
  4. Students take quiz at scheduled time
✅ Everything automatic. No manual steps needed.
B

Student approved BEFORE Week Config was saved

Admin approved a student but hadn't set up the week config yet. No quiz token was generated.

  1. Save the Week Config now
  2. Go to Registration Detail for this student
  3. Use the "Generate Link" button — assigns quiz + generates token
  4. Then click "Send Quiz Links to Approved" to send via email
⚠️ This student won't get a link from the bulk send unless you manually generate their link first.
C

Pre-Registration (no Week Label)

Student registered before a specific week was announced — their weekLabel is blank.

  1. Open Registration Detail
  2. Use "Generate Link" — pick a quiz manually and optionally set a week label
  3. Send their link manually or use bulk send
💡 Pre-reg students show a "Pre-Reg" badge in the table. Filter by "Pre-Registrations only" to see them.
D

Quiz with NO scheduled time

You saved the Week Config but left "Quiz Opens At" blank. No time-lock.

  1. Students get quiz link via "Send Quiz Links"
  2. They can open it immediately — no waiting
  3. No "Quiz Not Open Yet" screen appears
⚠️ Use this only if you want an always-open quiz (e.g. practice round).

Important Rules

Things to remember

🔐

Quiz token = access pass

Each student gets a unique UUID link. Only they can use it. It's useless without also being approved.

⏰

Time-lock is automatic

Set "Quiz Opens At" and the quiz page blocks access until that exact time. No manual action needed at quiz time.

📬

Two emails per student

1) Approval confirmation (no link). 2) Quiz link email (sent by you via "Send Quiz Links"). You control when #2 goes out.

🏆

Ranks auto-update

Every time a student submits, ranks for that week recalculate automatically. Highest score wins; tie-break is fastest time.

🔁

One attempt only

Once a student submits the quiz, their link shows "Already Submitted". They cannot retake it.

📋

Quiz Access Control setting

Ignore the "Access Control" dropdown on Quiz creation — that's only for internal LMS students, not public quiz.
