Phase 1 · Executive Summary

A broad, capable platform in its hardening stage

CodeBegun packs an LMS, an AI assessment engine, an interview platform, a full CRM, a placement suite, and an AI career stack into one multi-tenant codebase. Breadth is exceptional. The gaps are horizontal, not feature-shaped — they cluster in security hardening, automated testing, cost governance, and consolidation of duplicated/legacy subsystems.

What's genuinely strong

  • AI infrastructure (88%) — dual-provider failover gateway (OpenAI→Claude) with per-call ₹ cost logging to AiUsage.
  • Interviews domain (avg 84%) — real Claude interviewer brain with deterministic fallbacks + voice/avatar.
  • AI Communication Lab (90%) and Enrollment / AI day-wise Learning Plan (85%) — production-grade signature features.
  • Skill Assessment Funnel (82%) — end-to-end candidate→student→lead pipeline at ~₹0.10/candidate.
  • Lead Management (88%) — mature CRM core with configurable pipeline.

Top cross-cutting risks

Security (48%) — cross-tenant read/write on :id/:userId routes; unverified webhooks (/hms/webhook no HMAC, Meta HMAC fails-open, WhatsApp/Exotel unverified); JWT/encryption-key fallback to hardcoded constants; missing roleGuard on many newer routes; XP forgery; unauthenticated video stream.
Testing (6%) — ~6 test files across the whole repo. High regression risk on AI/scoring logic.
Cost governance — only LLM/Whisper metered; 100ms + Bunny Stream are unbounded "cost bombs" with no caps.
Reconciliation note: Razorpay payments are complete (order→verify→unlockCandidatePlans with webhook signature check) and Raise-a-Concern is complete — these correct earlier internal notes. The real assessment revenue blocker is the student-facing unlock UI, not the payment plumbing.

Phase 7 · Gap Analysis

The recurring gaps, by theme

Rather than 70× repetition, here are the gap patterns that appear across most modules — the highest-leverage places to invest.

🔒 Security & Permissions

  • Tenant-ownership not checked on :id routes
  • Webhooks unverified (hms, Meta fails-open, WhatsApp, Exotel)
  • Secret fallbacks (JWT 'secret-key')
  • Missing roleGuard on newer routes
  • Plaintext tokens (GitHub, Exotel)
  • No rate-limiting on public endpoints

🧪 Testing & Error Handling

  • ~6 test files repo-wide (≈6%)
  • No tests on scoring/grading/AI-fallback
  • Empty/loading/error states patchy in UI
  • No retry on transient AI/API failures

🔔 Notifications

  • No email/WhatsApp on: leave decision, career review, mentoring, result-ready, resource request
  • WhatsApp non-compliant (no HSM/STOP/suppression)
  • In-app only; single-instance socket

🤖 Automation

  • Daily challenges pull-only (no cron)
  • Seat expiry never triggers
  • Placement matching fully manual
  • Assignment expiry flags dormant

📊 Reports & Analytics

  • In-memory aggregations (no pipelines)
  • No unified BI / cost ledger
  • Conversion-funnel metrics absent
  • Interview analytics filters unwired

♻️ Tech Debt / Duplication

  • LiveClass(100ms) vs LiveSession(Jitsi)
  • Certificate vs shareToken systems
  • 3 interview/question models
  • 2 lead-scoring engines
  • Dead code: AdCampaign, scraper (699 L), Lesson.ts
  • Fabricated exec metrics (Math.random())

Phase 9 · AI Opportunities

Where AI already works — and where it should go next

Live AI today

  • Assessment: Claude exam design, question gen (Piston-verified), roadmap, skill-gap, resume/comms scoring.
  • Interviews: Claude interviewer brain, answer eval, transcript grading; ElevenLabs voice + D-ID avatar (opt-in).
  • Communication/Thinking Labs: Whisper STT + Claude/OpenAI rubric + gamification.
  • Learning: AI day-content generation (lessons + Q&A + verified DSA).
  • CareerPilot: resume/GitHub/LinkedIn review, AI mentor chat.
  • CRM: lead scoring, AI voice calls (Exotel), talk-tracks.

Highest-value AI to add

  • AI coding grader for assignments/quizzes (currently auto-0 / manual).
  • Placement matching engine (student readiness ↔ company reqs).
  • Prediction AI: dropout/at-risk, placement-likelihood, lead-conversion propensity.
  • Recommendation AI: next-best lesson/drill; semantic question dedup via embeddings.
  • Real body-language scoring for Communication Lab (currently null).
  • Provider consolidation onto Claude + meter all AI spend (AI Mentor/Speaking currently invisible).

Phase 11 & 13 · Prioritized Implementation Plan

What to do, in order

Sequenced by risk-reduction and revenue impact. Each priority lists estimated time, complexity, dependencies, business value, and technical risk. No work has been started — this is the plan for your approval.

P1 — Security & Correctness Hardening Must-have

⏱ 2–3 weeks🧠 Medium🔗 none (do first)💰 Very High (prevents breach)⚠️ Low risk
  • Enforce tenant-ownership on all :id/:userId routes; add roleGuard to newer routes (curriculum, learning-library, interactive-lesson, enrollment-plan, dashboard-admin, resume /all, career-profile admin).
  • Verify all public webhooks (hms HMAC, Meta HMAC fix fail-open→fail-closed, WhatsApp, Exotel). Remove JWT/encryption secret fallbacks.
  • Fix XP forgery (validate against scene.xpReward), authenticate the video-stream route, fix the double lead-assignment race, make the code runner fail-closed for scored work (no Math.random() metrics / simulation pass).
  • Rate-limit public endpoints (assessment register/verify/run-code, public quiz).

P2 — Trust & Revenue Must-have

⏱ 2–4 weeks🧠 Medium🔗 P1💰 High (unlocks revenue)⚠️ Medium
  • First automated test suite targeting scoring/grading/AI-fallback logic (highest-risk code).
  • Ship the assessment paid-unlock UI (payment plumbing already complete) — the direct revenue blocker.
  • Notifications: result-ready, leave decision, career-review complete, mentoring accept/decline.
  • WhatsApp compliance: HSM templates + STOP/opt-out + suppression list (currently non-functional at scale).

P3 — Cost & Scale High value

⏱ 2–3 weeks🧠 Medium-High🔗 P1💰 High (before scale)⚠️ Medium
  • Unified cost ledger (100ms min, Bunny GB, WhatsApp, Razorpay, Exotel) + per-tenant budget caps & alerts.
  • Redis Socket.io adapter (unblocks multi-instance / live-class scale-out).
  • Email queue + paid provider (Brevo/SES) with backpressure; keep SMTP fallback.
  • Pagination + N+1 fixes (quiz/question analytics, candidate lists, attendance summary).

P4 — Consolidation & Debt Good-to-have

⏱ 2–4 weeks🧠 Medium🔗 P1–P3💰 Medium (maintainability)⚠️ Medium
  • Retire Jitsi LiveSession; unify certificate systems; collapse 3 interview/question models & 2 lead-scoring engines.
  • Delete dead code (AdCampaign controller, Playwright scraper, Lesson.ts); decide Exam model (deprecate → AssessmentSubmission).
  • Consolidate AI onto Claude where product direction dictates; meter all AI spend.

P5 — AI Depth & Automation Enterprise / Premium

⏱ ongoing🧠 High🔗 P1–P4💰 High (differentiation)⚠️ Medium-High
  • Daily-challenge cron + reminders; AI coding/short-answer grader; auto-certificate issuance for all types.
  • AI placement-matching engine; prediction AI (at-risk / placement-likelihood / lead-conversion); recommendation AI.
  • Real body-language scoring; audit-log coverage across all admin actions; mobile support.
